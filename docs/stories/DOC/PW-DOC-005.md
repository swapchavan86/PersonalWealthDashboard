# PW-DOC-005 — Define tabular template/schema model

## Goal
Create a versioned schema model for CSV/Excel/tabular financial documents.

## Acceptance Criteria
- Fields can define source column, target field, required/optional status, type, format and normalization.
- Schema versions are explicit.
- Debit/credit and amount semantics can be represented without bank-specific business logic.
- Template definitions are testable.
